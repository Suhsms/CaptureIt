# Wildlife Spotter

Wildlife Spotter is an Android application designed to help users capture and identify various species of flora and fauna. The app allows users to take photos of wildlife, identifies the species, assigns points based on rarity and photo quality, and registers the user's location for species rarity evaluation.

## Features

- **Photo Capture**: Users can take photos of wildlife using the camera functionality.
- **Species Identification**: The app utilizes machine learning to identify species from the captured images.
- **Rarity Evaluation**: Each species is evaluated based on its rarity, and users earn points for their sightings.
- **Location Tracking**: The app records the user's location to assess species rarity in different areas.
- **Leaderboard**: Users can compete with others based on the points earned from sightings.

## Technologies Used

- Kotlin: The primary programming language for Android development.
- Room: For local data storage and management.
- Retrofit: For network operations and API calls.
- Dagger: For dependency injection.
- Jetpack Compose: For building the user interface.

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/wildlife-spotter.git
   ```
2. Open the project in Android Studio.
3. Sync the project with Gradle files.
4. Run the app on an Android device or emulator.
